Cygnus AI Labs — PRD
Original problem statement
Build a complete, production-quality single-page website for Cygnus AI Labs, an AI automation and intelligence company with a long-horizon ambition toward superintelligence. The site must feel like a serious, high-caliber organization from 2050: intellectually confident, cinematic, alive with movement, yet credible, human-directed, fast, and easy to navigate. It must not look like an AI-generated startup template. Use the supplied brand pack (logo with swan emblem in an orbital ring) as the source of truth for color and identity; do not redraw, recolor, or retype the logo. Content must contain no invented facts — use clearly labeled placeholders wherever company information is missing.

User choices (from ask_human)
Contact form: visual form with placeholders only, no submission handling (submit opens a prefilled mailto draft)
"How Cygnus works": small, tasteful disclaimer footnote
Typography: sharp geometric sans display
Architecture
Frontend: React 19 (CRA + craco) + Tailwind, framer-motion (reveals, accordion, panel transitions), lenis 1.3 (momentum scroll), lucide-react icons. No router — single page with anchor navigation via a lenis-aware scrollTo helper.
Backend: untouched FastAPI template (health at /api/) — no data features required by the brief.
Brand assets in /app/frontend/public/brand/: cygnus-logo.png (full logo, white→alpha, trimmed, ≤1100px), cygnus-emblem.png (900px square crop of the emblem), cygnus-emblem-300.png (nav/footer use); favicon.png + apple-touch-icon.png derived from the supplied emblem. Logo itself never recolored or redrawn — only background removal and crop.
Design system
Colors (from logo): navy #010619 base; cobalt #0154C9, bright blue #0287DF, teal #01A498, gold #FA9720 accents; coral #FB5040 rare; warm paper #F6F3EB for alternating light sections; gold marquee strip as the one saturated brand moment.
Type: Archivo variable (font-stretch 112% display, tight tracking) + IBM Plex Mono for annotations, kickers, figure labels, placeholders.
Texture: light SVG-turbulence grain overlay; graph-paper grid on hero; hairline rules throughout.
